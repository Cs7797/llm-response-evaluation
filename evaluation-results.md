# Evaluation Rubric

Each criterion receives a score from 0 to 2.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Factual correctness | Major factual errors | Partially correct | Factually correct |
| Source grounding | Unsupported or contradicted claims | Mixed support | Claims supported by the source |
| Instruction-following | Fails the task | Partially answers | Directly answers |
| Completeness | Omits key requirements | Omits some details | Covers key requirements |
| Clarity | Difficult to understand | Understandable but imperfect | Clear and concise |

## Scoring Principles

- Evaluate each criterion separately.
- Cite specific text from the source when identifying factual errors.
- Distinguish a contradicted claim from a claim that the source simply does not address.
- Do not reward confident wording when evidence is missing.
- Apply the same criteria to both responses.
- Explain every score that materially affects the final ranking.

Maximum score: 10 points per response.

The rubric is a custom practice framework, not a universal evaluation standard.
