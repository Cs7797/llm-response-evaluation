# LLM Response Evaluation Portfolio

## Overview

An independent practice project demonstrating a structured approach to evaluating large language model (LLM) responses using source-based verification and a consistent scoring rubric.

## Objectives

- Compare competing AI-generated responses.
- Assess factual correctness and source grounding.
- Identify hallucinations and unsupported claims.
- Evaluate instruction-following, completeness, and clarity.
- Produce evidence-based scores and comparative judgments.

## Methodology

1. Establish a source document as the reference.
2. Define the user question and evaluation criteria.
3. Review each candidate response independently.
4. Identify supported, contradicted, and unsupported claims.
5. Assign rubric-based scores.
6. Select the preferred response and justify the decision with evidence.

## Evaluation Criteria

- Factual correctness
- Source grounding
- Instruction-following
- Completeness
- Clarity

Each criterion is scored from 0 to 2 using the rubric in `evaluation-rubric.md`.

## Sample Evaluation

The sample compares two responses to a fictional refund-policy question. The responses are evaluated against the same source document.

See `evaluation-results.md` for the complete analysis.

## Limitations

This is a small, manually scored practice exercise using synthetic policy data and constructed responses. It is not a formal benchmark and does not establish general model performance.

LLM response evaluation, factuality checking, source grounding, hallucination detection, comparative analysis, rubric-based scoring, and technical writing.
